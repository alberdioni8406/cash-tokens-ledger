Where this data comes from

The directory, supply figures, UTXO counts and holder counts come from TokenStork's public on-chain index, which itself is built on Paytaca's BCMR indexer and a Chaingraph install. Names, icons and descriptions are enriched from the Paytaca BCMR API when a token's on-chain record is sparse. Genesis blocks and timestamps are read directly from the chain via TokenStork's index. This page holds no private keys, makes no transactions, and reads only — it is a window onto public on-chain and registry data, not a wallet.

Some tokens carry no icon, no symbol, or an unverified on-chain record — that's shown honestly as unverified rather than hidden or guessed at. Metadata like descriptions and icons is supplied by each token's issuer and is not vetted for accuracy by this dashboard, TokenStork, or BCMR.

Directory refreshes every few minutes; the list itself can hold ~19,000+ categories, so it's paged rather than loaded in full.
